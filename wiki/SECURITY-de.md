# Sicherheitsrichtlinie

[English](SECURITY.md)

Melde vermutete Sicherheitslücken vertraulich über [Security → Report a vulnerability](https://github.com/deckerweb/shortcode-item-updated/security/advisories/new). Nenne Plugin- und Komponentenversion, WordPress/PHP-Version, Schritte zur Reproduktion und Auswirkungen. Keine Passwörter, Tokens oder Kundeninhalte mitsenden. Normale Supportfragen gehören in die Issues.

Ist das private Formular nicht verfügbar, nutze einen bestehenden privaten GitHub-Kontakt zum Repository-Inhaber; veröffentliche keine Angriffsdetails in einem Issue.

Meldungen werden vertraulich bewertet. Fehlerkorrektur und Offenlegung werden mit dem Melder abgestimmt; es gibt keine garantierte Reaktionsfrist. Verwende die aktuell gepflegte Pluginversion. Diese Richtlinie umfasst auch die in diesem Host mitgelieferte deckerweb Library und den Updater.
